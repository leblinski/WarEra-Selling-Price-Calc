Settings and fallbacks

Tax added on top of your figure. Set 0 to enter the price directly.

Tick override. Leave at 0 to use the value detected from live prices.

Try the WarEra Stats gateway first. Useful if the direct API blocks browser requests.

If the browser can't reach the API at all, open the endpoint in a tab and paste the JSON here.

Tick size is worked out by counting the decimal places across every price in the book. If prices are all three decimals the tick is 0.001; if any price carries more, the tick shrinks to match, and your beating price follows.

The big figure already has tax divided out, so type it in as-is. The listed price shown beside it is what buyers will see afterwards.

Endpoints used: itemTrading.getPrices for the item list, tradingOrder.getTopOrders for the book. Unofficial, and it may break when the game updates.
